# ImagePeek 隐私说明

最后更新：2026-08-26

ImagePeek 是本地运行的 macOS 菜单栏应用。它不提供账号系统，不内置广告、分析 SDK 或开发者控制的中转服务器。

## 会读取什么

- 当 WPS、Microsoft Excel 或支持的飞书 Sheets 位于前台时，ImagePeek 读取当前选中单元格中公开的文本，以识别图片 URL 或本地图片路径。
- 若你开启“Preview selected image URL anywhere”，ImagePeek 仅尝试读取前台应用通过 macOS 辅助功能公开的**已选中文本**。不兼容的应用会被静默跳过。
- WPS 的可选剪贴板兜底会暂时将当前单元格内容写入剪贴板，读取后立即恢复原始剪贴板内容。可在 Settings 中关闭。

## 图片与缓存

- 对远程图片，ImagePeek 直接向该图片 URL 的宿主服务器请求数据；该服务器可能记录常规网络信息，例如 IP 地址、请求时间和 User-Agent。ImagePeek 不会把 URL 转发给开发者服务器。
- 图片数据会被缓存在本机的内存和磁盘中，用于加快再次预览。你可在 Settings 中查看摘要、设置上限/保留时间并随时清除。
- 本地图片仅从你选择的本机路径读取。

## 系统权限

- **辅助功能**：用于读取前台应用公开的选中内容，并在需要时控制 Microsoft Excel 读取活动单元格。ImagePeek 不需要屏幕录制权限，也不使用 OCR。
- **输入监控**：ImagePeek 不请求输入监控权限，也不安装监听所有按键的系统级事件拦截器。预览显示且前台为受支持表格时，它只向 macOS 临时注册 `Space`、`Esc`、`⌥C`、`⌥O`、`⌥R`、`⌥P` 这 6 个热键；预览隐藏或切换应用后会立即注销。
- **开机自启**：只在你打开该选项后注册 ImagePeek 为登录项。

## 数据不做什么

ImagePeek 不上传表格、选中文本、图片缓存或权限状态到开发者服务器；不录制屏幕；不使用 OCR；不读取浏览器 Cookie、密码、账户或剪贴板中的无关内容。

## 反馈

GitHub Issue 是公开的。提交反馈时请删除真实图片 URL、订单信息、账号、Cookie、密钥及其他敏感数据。
